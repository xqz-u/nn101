1. Receive input (accept right dimensionality)
2. Loop through layers:
   * Pass the tensor through the layers

3. Compute loss


Backward pass:
1. Kick-off backprop: compute loss grads wrt network output
2. Chain-rule them through softmax (classification) + each
   (linear layer, activation fuction) tuple.
   Each module (besides loss) needs to remember the last input they worked on.
   Linear module has learnable parameters (weights + bias).
3. Now that each layer has its own gradients, perform gradient descent on the
   learnable parameters.
